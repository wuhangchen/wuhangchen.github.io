Jetson 系列（一）：Orin 安装 Jetpack

在本文中，您将找到在主机上安装 Jetpack 的指南。本部分假设您已经安装了 NVIDIA SDK Manager，要了解 SDK Manager，请查看安装 SDK Manager 部分。

以下小节介绍了在主机上安装 Jetpack 5.0.2 的四个步骤：

STEP 01 选择硬件配置

1. 通过在终端中运行以下命令启动 sdkmanager UI

sdkmanager

此时，您应该会看到登录窗口。登录后，您应该会看到类似于下图的环境配置选项。

2. 选择产品类别

根据安装的 SDK Manager 版本，将有一两个选项。对于 SDK Manager 版本 1.8.0.10363，选项为 DRIVE 和 Jetson。请确保选择 Jetson 选项，如上图所示。在较旧的 SDK Manager 版本中，唯一可用的选项是 Jetson，如下图所示。

3. 选择 Jetson AGX Orin 模块作为目标硬件

此选项应出现在目标硬件下拉列表下，如上图所示。或者，您也可以选择主机选项，以便在第 2 步中选择在主机上安装一些开发人员工具的选项。可以同时选择主机和 Jetson AGX Orin 选项。

4. 从目标操作系统下拉列表中选择 JetPack 5.0.2

类似于下图。

5. 您也可以选择安装 DeepStream SDK

方法是选中”附加 SDK”选项。选择目标硬件和操作系统后，将出现此选项，如下图所示。

6. 准备就绪后，单击”继续至 STEP 02”按钮

STEP 02 软件包选择和许可

1. 软件组件安装

在此阶段，SDK 管理器将显示可安装在您的计算机（主机）和 Orin（目标或设备）中的软件组件，请参见下图。对于主机，您可以选择安装与 CUDA 相关的工具、VPI 库和 Nsight。对于目标组件，请确保选择 Jetson OS 选项。您也可以选择 Jetson SDK 组件。

2. 软件包选择

可选择下载和目标硬件图像文件夹。默认情况下，SDK 管理器会将所有需要的文件下载到 /home/ 目录，并在目录 USER/nvidia/nvidia_sdk 中设置 JetPack SDK 文件，如上图底部所示。

3. 安装 JetPack SDK 组件

准备就绪后，选中带有以下选项的复选框：我接受许可协议的条款和条件，类似于上图，然后按下按钮继续到 STEP 03。

4. 此时，SDK 管理器将要求您输入 sudo 密码才能安装 JetPack SDK 组件

如下图所示。

STEP 03 设置过程

1. 现在 SDK 管理器将开始下载并设置所需的组件

您应该会看到类似于下图的窗口。

2. 刷新 AGX Orin

SDK 管理器完成主机环境设置后，将打开一个提示，允许用户刷新 AGX Orin，类似于下图。此时，您可以选择使用 SDK 管理器 UI 刷新 Orin 或暂时跳过刷新。

如果您希望在不进行任何修改的情况下测试 JetPack OS，您可以立即继续刷新主板。有关更多详细信息，请查看使用 GUI 安装程序刷新主板部分。

如果您想自定义内核或设备树，那么您可能希望暂时跳过刷新，然后查看编译源代码和从命令行刷新主板部分。

STEP 04 完成

1. 验证

无论您选择刷新 Orin 还是跳过刷新，您都应该看到安装到主机和目标的软件组件的摘要以及成功消息，如下所示。您现在可以关闭 SDK 管理器。
